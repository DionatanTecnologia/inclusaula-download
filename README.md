# Inclusaula para Windows

Programa do Inclusaula para computador. O ChatGPT abre ao lado das suas atividades: você cria, copia e cola sem trocar de aba.

## Como instalar

1. [Baixe o instalador](https://github.com/DionatanTecnologia/inclusaula-download/releases/latest/download/Inclusaula-Instalador.exe).
2. Abra o arquivo baixado.
3. Se o Windows mostrar um aviso, clique em **Mais informações** e depois em **Executar assim mesmo**.
4. Entre com a mesma conta que você usa no site.

Funciona no Windows 10 e 11 e precisa de internet.

Dúvidas: https://inclusaula.pages.dev
